# `compose-wordpress-items`

This python3 script takes a collection of XML files (typically as generated by [`extract-wordpress-items`](./extract-wordpress-items.md)), and constructs a WordPress archive ready for importing.

## Command Line

`compose-wordpress-items` takes the following basic command line.

```bash
python3 compose-wordpress-items.py {switches} input-dir [output-filename]
```

`input-dir` is the name of the directory to be read, as prepared by `extract-wordpress-items`. It must contain `Header.xml`. The script reads each item from `input-dir/xml/`_`name`_`.xml`, and fills in `<content:encoded>` and `<excerpt:encoded>` from `input-dir/html/`_`name`_`-content.html` and `input-dir/html/`_`name`_`-excerpt.html`. If an HTML file is missing, the script leaves that element as it is in the XML file. With `--combined-xml-html`, the script reads the item files directly from `input-dir` and uses the HTML inside them. If the file formats are not correct, the script will probably crash with an exception.

The script writes items in order of `<wp:post_type>`, then numeric `<wp:post_id>`.

`output-filename` is the name of the XML file to be written. If not specified, the file is written to standard output.

Recognized switches:

Switch | Function
-------|----------
 `-v`, `--verbose` | Print progress messages.
 `-h`, `--help`    | Print help summary.
 `--include {type}`, `-i {type}` | Include only items with specified value of `wp:post_type`. Repeat to include several types. If not specified, all items are included.
 `-c`, `--combined-xml-html` | Read the older layout written by `extract-wordpress-items --combined-xml-html`.
